The launch is authorized by the owner. The inventory combines the 39 visible
Search Console Performance URLs with the 30 topic links collected from the old
homepage and site tree before DNS changes. Search Console's indexing and external
links reports were still processing, so this is not a claim that every historic
URL or backlink has been discovered. Raw exports and HTTP evidence stay in the
private `atd-lt-audit/migration-2026-10-19` directory.

## Verification and retention

`npm run test:migration` uses Next's actual redirect matcher. HTTP checks additionally
verify the hash and query combination, final200 responses and the target anchor.
The experimental Next test helper incorrectly concatenates a query after a
destination hash; the running server is the authority for that combination.

Retain migration redirects for at least a year, preferably indefinitely. Continue
checking Search Console and server logs for previously unknown old URLs after
launch. Add a redirect only where a relevant replacement exists. Reference:
[Google site migration guidance](https://developers.google.com/search/docs/crawling-indexing/site-move-with-url-changes).
